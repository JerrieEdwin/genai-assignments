Overview

A clearer view of every release.

DeployLens turns two manually captured deployment states into an understandable visual comparison.

Definition

DeployLens is a release UI change explorer. It captures the visible viewport of a route you explicitly choose, compares it with the matching route in another release, and highlights pixel-level differences in a heatmap.

What it means for teams

Manual testers can focus regression checks on changed regions. Developers can review visible evidence alongside optional release metadata. Every result remains clearly labeled as visual evidence—not an automated code diagnosis.

Privacy and boundaries

Useful without overreaching.

DeployLens is intentionally local, explicit, and honest about what it can and cannot determine.

DeployLens does

  • Capture the active tab only after an explicit action
  • Store releases, screenshots, and settings locally
  • Compare matching viewport dimensions
  • Use pasted commit and file metadata without attribution claims

DeployLens does not

  • Crawl sites or capture background tabs
  • Read passwords, cookies, tokens, or autofill data
  • Send screenshots or URLs to a server or AI service
  • Prove which source code caused a visual change
